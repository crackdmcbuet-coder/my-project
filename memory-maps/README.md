প্রতিটি ফাইল একটি self-contained HTML — ডাউনলোড করে যেকোনো ব্রাউজারে খুললেই চলে।

## গঠন

প্রতিটি ম্যাপে ১৫টি পর্ব — মাস্টার ম্যাপ, সব উদাহরণ, সম্পূর্ণ প্রোফাইল, তুলনা,
কনফিউশন জোন, প্যাচ, সব সংখ্যা, ফিচার→জীব, জনন, রোগ, অর্থনৈতিক গুরুত্ব,
MCQ ক্লু, মেমোরি হুক, র‍্যাপিড রিভিশন, মাস্টার মেমোরি গ্রাফ।

প্রতিটি তথ্যের পাশে `[স্লা.__ · পৃ.__]` — PDF-এর স্লাইড ও বইয়ের পৃষ্ঠা নম্বর।
